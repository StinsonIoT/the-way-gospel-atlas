## Original generated concept sheet
- [Original concept sheet](./gospel-atlas-original-concept.png) — the AI-generated six-panel raster concept (1536 × 1024) created in the ChatGPT conversation on 2026-10-20. It was added to the repository after the SVG below, in commit `b2b5eb0`.
- The SVG board above is a separate, simplified vector reference (palette and layout only, no map content). It is not the original image and must not be represented as it.

Use the concept sheet for mood, palette, light and composition only. It is not a map: for example it labels one place twice, draws continuous route lines that read as roads, and gives Jerusalem building detail that no source supports.

## Evidence warning
These illustrations are **concept art, not georeferenced or historically validated maps**. Do not extract coordinates, coastlines, routes, ancient city geometry, labels, chronology or archaeological claims from them. Use the source/evidence requirements in ../HISTORICAL-ACCURACY.md and ../ATLAS-MASTER-PLAN.md. Do not implement designs without review and explicit approval.

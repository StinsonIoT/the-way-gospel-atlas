# Codex instructions — The Way Gospel Atlas

Read CLAUDE.md and all five docs/* atlas planning files before beginning related work. Treat them as project requirements, not evidence that proposed features are already implemented.

Work incrementally, preserve current functionality and Git history, and do not deploy or merge without explicit permission. Do not modify production merely to fulfill a research/design request. Check repository reality, existing components, tests and scripts first.

Historical accuracy is mandatory: distinguish Gospel text, archaeological support, tradition, reconstruction, disputed candidates and unknowns. No invented exact coordinates, roads, chronology, Egypt destinations, or ancient Jerusalem buildings. Label approximate geometry and schematic links. Use longitude-latitude GeoJSON and stable IDs.

Respect mobile safe areas, accessible interaction, keyboard use, reduced motion, readable Scripture, map loading fallbacks and existing reading position. Cite sources and licenses for geographic data and external assets.

Before implementing, propose a scoped plan and testing/rollback approach. Verify builds and test behavior at mobile and desktop sizes; document what was and was not tested.

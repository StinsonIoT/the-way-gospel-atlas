# Claude Code instructions — The Way Gospel Atlas

Read docs/PROJECT-VISION.md, docs/ATLAS-MASTER-PLAN.md, docs/HISTORICAL-ACCURACY.md, docs/MAP-DESIGN-SYSTEM.md and docs/IMPLEMENTATION-ROADMAP.md before proposing atlas work.

## Non-negotiables
- Preserve the existing site, code, story scenes, interactive behavior, and deployed GitHub Pages experience. Do not replace or redesign the site wholesale.
- Documentation work is not permission to implement. Make code changes only when explicitly requested.
- Inspect the current repository and tests before suggesting implementation; do not assume features are absent.
- Four canonical Gospels and Acts 1 are narrative primary sources. BSB quotations must be checked for accuracy and appropriate usage rights.
- Never invent ancient roads, coordinates, buildings, event chronology, destinations in Egypt, or exact event sites.
- Separate biblical statements, archaeological evidence, traditional identifications, scholarly proposals, and unknowns.
- Preserve uncertainty in map symbols, descriptions, data properties, and route behavior.
- Keep the experience iPhone-first, accessible, responsive, performant, and compatible with reduced motion.
- GeoJSON geographic coordinates are [longitude, latitude]; separate georeferenced data from concept artwork.
- Do not deploy, merge, or alter production without explicit authorization.
- Before changes: report affected files, risks, rollback plan, and validation steps.
